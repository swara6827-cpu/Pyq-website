# UPSC Prelims PYQ Practice

A free, static website for practising UPSC Civil Services Preliminary Examination previous-year questions.

## Status

Initial project setup. The question bank and website features will be added next. Any sample questions must be clearly labelled as demos until verified against official papers.

## Planned features

- Practice mode and timed test mode
- Subject and year filters
- Bookmarks and mistake notebook
- Progress saved locally in the browser
- JSON-based question bank for easy future updates
- Free static hosting through GitHub Pages or Vercel
