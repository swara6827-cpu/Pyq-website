# Third-party notices and answer-key provenance

This repository is an independent study tool. It is not affiliated with or endorsed by the Union Public Service Commission (UPSC).

## Question and answer sources

Question text, four-option choices and keyed answers are transcribed from public year-wise GS Paper I previous-year-question pages, including:

- UPSC Answer Check — https://upscanswercheck.com/prelims/pyq/
- UPSCprep — https://www.upscprep.com/
- UPSC official previous question papers — https://www.upsc.gov.in/examinations/previous-question-papers
- UPSC official answer-key archive — https://www.upsc.gov.in/examinations/answer-key/archives

When the parser cannot recover a complete four-option item from the primary page, it may append a clearly labelled supplemental record from an alternate public page. Supplemental question numbering is marked separately because the public sources can use different set orders.

## Explanations and study notes

Some explanation text and revision notes are adapted from the public community repository:

https://github.com/mailmeatdarshan/UPSC---TestBook

Its README declares an MIT licence and describes its explanations as Vision IAS-inspired. The linked LICENSE file was not accessible in the public repository snapshot checked while this website was prepared, so this repository cannot independently confirm the precise licence terms applying to every bundled explanation. This notice is not a substitute for obtaining permission where required.

Explanations are third-party or community-sourced, not official UPSC commentary. The importer tries to match them to questions by wording and flags some records for review, but automated matching cannot guarantee factual correctness. Verify important, disputed or recent answers with the official UPSC paper and answer key.

## Usage and limitations

- General Studies Paper I only; CSAT / GS Paper II is intentionally excluded.
- Question sets and answer keys can differ in numbering across sources.
- Recent answer keys may be provisional until the official UPSC key is published.
- This project is provided as a study aid. It makes no guarantee that every transcription or explanation is error-free.
